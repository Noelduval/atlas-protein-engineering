# Gate-3 completed campaign

This directory is a curated, durable subset of the completed Colab export `atlas-adaptive-t4-aa5f61d8a5fb-e8f61394df86c741694affb8b3067f4e17ac72245a37e7cdd9cf875dc9efe63a`.

The campaign completed with 5,000 unique legal candidates, 500 broad survivors, 146 structural analyses, 10 adversarial-review candidates, and 5 selected finalists. The authoritative machine-readable records are `completion_audit.json`, `reproducibility_manifest.json`, `finalist_evidence.{csv,json}`, and `final_selection_trace.json`.

The package includes finalist dossiers, structures, FASTA files, evidence, provenance, limitations, and key figures. The full candidate library, evidence ledger, SQLite/JSONL design memory, intermediate stability outputs, repair records, and non-finalist structures were omitted from git because they are large transient checkpoints; their original exported location is recorded in the source ZIP and manifest.

All finalists are computationally prioritized, experimentally untested DP622-inspired metalloprotease hypotheses recommended for wet-lab evaluation. No file here demonstrates catalytic activity, cleavage, therapeutic efficacy, or patient benefit.

See [`FINALIST_SUMMARY.md`](FINALIST_SUMMARY.md) for the reviewer-facing summary.
